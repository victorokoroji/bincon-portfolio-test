# Bincom Test - Victor Personal Website

This project is a personal portfolio website designed to showcase my skills, projects, qualifications, and professional background. It is a responsive and interactive website built to highlight my expertise as a **Frontend Web Developer**, **UI/UX Designer**, and **Mobile Development Enthusiast**.

![screenshot](./assets/images/Screenshot%202025-04-11%20093915.png)

he website includes the following sections:

- **Home**: A brief introduction about me.
- **About Me**: Details about my expertise and personality.
- **Skills**: Highlights of my specialization in UI/UX, web development, and mobile development.
- **Portfolio**: A showcase of my latest projects.
- **Qualification**: My educational background and professional training.
- **Gallery**: A collection of images related to my work and collaborations.
- **Footer**: Links to my social profiles and a call-to-action for collaboration.

## Built With

- HTML5, Javascript
- CSS3

## Getting Started

To get a local copy up and running follow these simple example steps.

## Prerequisites

- Have a good knowledge on how to parse UI designs
- Have VSCode or other text editor installed. [Link to download VSCode](https://code.visualstudio.com/download)
- Install node package. [Link to download node](https://nodejs.org/en/download/)
- Have git installed.[Link to download git](https://git-scm.com/downloads)
- Create a github repository.

## Setup

- git clone https://github.com/victorokoroji/bincom-portfolio-test.git
- cd bincom-portfolio-test/

## Deployment

- Use GitHub pages to deploy website
- For more information about publishing sources, see [About github pages](https://pages.github.com/)
